# Velloxa

Velloxa is a responsive fashion and lifestyle e-commerce website built as a
front-end portfolio project. It covers clothing, footwear, watches, bags,
jewellery, gadgets and beauty products.

## Features
- Mobile-friendly navbar with a toggle menu
- Dismissible offer bar
- Auto-sliding category carousel with dots
- Deals row with left and right arrow buttons
- Product grids with ratings, prices and discounts
- Live product search that filters as you type
- Men's, women's and kids' collection pages
- About and Contact pages

## Built With
- HTML5
- Tailwind CSS (v2.2.19)
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts (Playfair Display)
